## 1. 파이썬의 주요 특징 3가지
- **인터프리터 언어**: 컴파일 없이 코드를 한 줄씩 읽어 기계어로 변환하며 실행
- **동적 타입 언어**: 변수의 자료형이 실행 중에 결정되고 바뀔 수 있음
  - C 예시: `int a = 10;`으로 선언하면 a에 10.4를 넣을 수 없음
  - 파이썬: 같은 변수에 정수, 실수, 문자열을 차례로 대입 가능
- **플랫폼 독립적 언어**: OS 제약이 적음

```python
a = 10
print(type(a))   # <class 'int'>
a = 10.4
print(type(a))   # <class 'float'>
```

## 2. 키워드 (Keyword)
- 파이썬이 문법을 위해 예약해 둔 단어 (`for`, `if`, `while` 등)
- 변수명, 함수명으로 사용 불가

```python
import keyword
print(keyword.kwlist)   # 키워드 전체 목록 확인
```

## 3. 식별자 (Identifier) 규칙 5가지
- 식별자: 변수, 함수 등에 붙이는 이름. 어떤 값을 가리키는지 알 수 있게 짓는 것이 원칙
- 영문자, 숫자, `_`만 사용 가능하며 대소문자를 구분
- 숫자로 시작할 수 없음
- 키워드는 사용할 수 없음
- `_`를 제외한 특수 기호는 사용할 수 없음
- 길이 제한은 없음
- 표기 방식
  - snake_case: `user_name`
  - camelCase: `userName`

## 4. 문장 (Statement)
- 인터프리터가 한 줄씩 실행하므로 기본은 한 줄에 한 문장
- 줄바꿈이 필요하면 백슬래시 `\`로 이어 쓰기
- 한 줄에 여러 문장은 `;`로 구분 가능
- 괄호 `()`, `[]`, `{}` 안에서는 줄을 바꿔도 하나의 문장으로 처리
  - 자료구조의 item을 여러 줄에 나눠 적을 때 사용

```python
total = 1 + 2 + 3 + \
        4 + 5
a = 1; b = 2
numbers = [1, 2, 3,
           4, 5, 6]
```

## 5. 들여쓰기 (Indentation)
- 코드 블록을 구분하는 방법 (다른 언어는 `{}` 사용)
- 같은 들여쓰기 수준의 코드가 하나의 블록
- 들여쓰기에 따라 코드의 영향 범위와 실행 여부가 결정됨

```python
a = 10
if True:
    print(a)   # if 블록 안: 조건이 참일 때만 실행
print(a)       # if 블록 밖: 항상 실행
```

### 비유로 이해하기
- 양치하기, 샤워하기, 머리 말리기를 순서대로 처리
- "머리를 감았으면 드라이기 사용"처럼 조건에 속하는 동작은 한 칸 안쪽에 둠

## 6. 주석 (Comments)
- `#`: 한 줄 주석
- `'''` 또는 `"""`: 여러 줄 주석
- 작성자, 작성일, 라이선스, 중간 과정 설명, 메모 용도로 사용

## 7. 독스트링 (Docstring)
- 함수 선언문(`def`) 바로 아래에 `""" """`로 작성한 설명문
- 함수 안에 있어야 독스트링으로 인정됨
- `__doc__`로 확인 가능

```python
def add(a, b):
    """두 수를 더해 반환한다."""
    return a + b

print(add.__doc__)   # 두 수를 더해 반환한다.
```
