## 1. 문제 정의
- 사용자와 컴퓨터가 가위바위보를 해서 5판 3승제로 승부
- 처리 단계
  - 사용자와 컴퓨터가 가위, 바위, 보를 선택
  - 서로 비교해 결과 판단
  - 승자의 이긴 횟수를 누적
  - 사용자나 컴퓨터가 3승이 될 때까지 위 과정을 반복
- 설계 포인트
  - 숫자 비교(숫자를 설정)보다 문자로 이기고 지는 것을 설정하는 편이 직관적
  - 승, 패, 비김을 정하고 `count`로 누적
  - 반복 횟수가 정해지지 않았으므로 `while` 사용
  - 사용 구문: `if ~ elif ~ else`, `while`, `for`, `break`, `pass`, 함수, lambda

### 조건 분기를 처음 생각한 방식
- 컴퓨터가 가위일 때: 사용자 주먹은 승, 보는 패, 가위는 비김(다시)
- 바위일 때: 보는 승, 가위는 패
- 보일 때: 가위는 승, 주먹(바위)은 패
- 비기면 `continue`

## 2. 순서도
- 사용자 입력(가위, 바위, 보)
- 컴퓨터 선택
- 비교
  - 사용자 승
  - 컴퓨터 승
  - 비김 (같으면 다시)
- 사용자 승 횟수, 컴퓨터 승 횟수 `count` 누적
- `count >= 3`이면 결과 출력 후 종료, 아니면 처음으로 반복

## 3. 컴퓨터 선택: random
- `random.randint(0, 2)`로 0~2 사이의 숫자를 무작위로 뽑음
- 숫자를 가위, 바위, 보 문자로 바꾸어야 문자 비교가 가능

### 방법 1: 리스트 인덱스
```python
import random

rps = ['가위', '바위', '보']
com = random.randint(0, 2)
com = rps[com]
```
### 방법 2: 딕셔너리
```python
rps = {0: '가위', 1: '바위', 2: '보'}
```

### 사용자 입력 검증
- `if 입력 in ['가위', '바위', '보']:`로 오타 방지
- 잘못 입력하면 다시 입력받아야 하므로 `while True`와 `break` 사용 (반드시 break 필요)

## 4. 결과표 만들기
- 입력은 2개(사용자, 컴퓨터)이고 관계는 고정되어 있음
- 결과를 미리 만들어 두고 나중에 가져다 쓰면 매번 계산하지 않아도 됨

| 사용자 \ 컴퓨터 | 가위 | 바위 | 보 |
|---|---|---|---|
| 가위 | 비김 | 컴 승 | 사용자 승 |
| 바위 | 사용자 승 | 비김 | 컴 승 |
| 보 | 컴 승 | 사용자 승 | 비김 |

- 입력이 2개이면 2×2 표, 5개면 5×5 표 형태로 접근 방식은 동일함

### 표를 저장하는 방법
- 변수에 저장할 값(item)이 많으므로 list, tuple, dict 중 선택

#### list (2차원)
```python
table = [
    [None, '컴', '사'],   # 사용자 가위: 비김, 컴 승, 사용자 승
    ['사', None, '컴'],   # 사용자 바위
    ['컴', '사', None],   # 사용자 보
]
print(table[0][2])   # 사
```

#### dict 안의 dict
- 인덱스 접근이 직관적이지 않으면 dict 형태로 만들 수 있음

```python
table = {
    '가위': {'가위': None, '바위': '컴', '보': '사'},
    '바위': {'가위': '사', '바위': None, '보': '컴'},
    '보':   {'가위': '컴', '바위': '사', '보': None},
}
print(table['가위']['보'])   # 사
```
- `None`은 비김을 의미

## 5. 승리 횟수 변수
- 0부터 시작해야 하므로 처음(위쪽)에서 선언
- 방법 1: `사_승리횟수 = 0`, `컴_승리횟수 = 0`
- 방법 2: 딕셔너리 `승리 = {'사': 0, '컴': 0}`

## 6. 함수로 통합
- 사용자와 컴퓨터가 각각 선택하는 동작을 하나의 함수로 합침
  - 사용자는 `input`으로, 컴퓨터는 `random`으로 동작
- 승부 결정과 승 횟수 누적도 함수로 분리
- 반복되는 부분은 `while True` 부분뿐이라 시간 절약, 코드 파악이 쉬움

### 최종 코드
- 사용 라이브러리: 표준 라이브러리 `random`

```python
import random

RPS = ['가위', '바위', '보']
TABLE = {
    '가위': {'가위': None, '바위': '컴', '보': '사'},
    '바위': {'가위': '사', '바위': None, '보': '컴'},
    '보':   {'가위': '컴', '바위': '사', '보': None},
}


def 가위바위보_선택(누구):
    """누구가 '사용자'면 입력을, 아니면 random으로 선택을 반환한다."""
    가위바위보 = None
    if 누구 == '사용자':
        while True:
            가위바위보 = input("가위, 바위, 보 중 선택: ")
            if 가위바위보 in RPS:
                break
            print("다시 입력하세요.")
    else:
        가위바위보 = RPS[random.randint(0, 2)]
    return 가위바위보


def 승부결정(사, 컴, 승리횟수누적):
    """승자를 판정해 승리 횟수를 누적하고 반환한다."""
    승자 = TABLE[사][컴]
    if 승자 is not None:
        승리횟수누적[승자] += 1
    return 승리횟수누적, 승자


승리횟수 = {'사': 0, '컴': 0}   # 승리 횟수 (변수)

while True:                       # 동작 주도
    사 = 가위바위보_선택('사용자')
    컴 = 가위바위보_선택('컴퓨터')
    승리횟수, 승자 = 승부결정(사, 컴, 승리횟수)
    print(f"사용자: {사}, 컴퓨터: {컴}, 결과: {승자 or '비김'}")
    if 승리횟수['사'] >= 3 or 승리횟수['컴'] >= 3:
        break

print("최종 결과:", 승리횟수)
```

### 개발 과정에서 얻은 교훈
- 조건을 작성하고 확인
- 중복을 합치고 밖으로 빼냄
- 확인하면서 합쳐 완성본을 만듦
- 주소 확인: `id()`로 확인해 중복된 작업을 밖으로 빼내기 (속도 지키기)
- 한 번에 찾아갈 수 있는 것도 합쳐 줌
- 1차 완성 (while, 선택, 승부결정, 누적), 2-1차 (주소 확인), 2-2차 (선택 함수), 2-3차 (승부 결정 함수), 최종 완성 순서
