## 표기 규칙
- **굵게**: 노트에서 형광펜·밑줄로 강조한 부분
- `보충`: 노트 내용과 사실이 달라서 바로잡거나 덧붙인 부분
- ※: 따로 기억하거나 익숙해져야 할 공부 포인트
- `참고` 섹션: 노트 끝에 모은 실습 · 복습 할 일
- 그림: 노트 내용을 바탕으로 새로 그린 것 (흐름도 = Mermaid, 그래프 = matplotlib, 이미지 파일은 `assets/`)
