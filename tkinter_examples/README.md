# tkinter_examples

tkinter 기본 위젯과 이벤트 처리 방식을 따라 하며 익힌 예제 3개입니다.

---

## 🪟 기본 창과 위젯

> 빈 창부터 Label, Button, Entry까지 기본 위젯을 하나씩 띄워 본 예제 *(위젯 · 이벤트)*
>
> - 주요 내용: 창 설정, Label 속성, 클릭하면 숫자가 바뀌는 Button 카운터, Enter 키로 계산
> - 실행: 예제 여러 개가 들어 있어서, 창을 닫으면 다음 예제 창이 열림
>
> [코드 보기 →](./20260306_tkinter_basics.py)

## 🔤 텍스트 요소와 입력 검증

> Label 스타일, Entry 입력 검증, Text · ScrolledText, Frame 배치를 연습한 예제 *(입력 · 배치)*
>
> - 주요 내용: StringVar로 화면 갱신, 빈 값 · 숫자 검사와 경고 창, 읽기 전용 Entry
> - 실행: 앞부분 예제는 주석 처리되어 있어서, 마지막 Text 예제만 실행됨
>
> [코드 보기 →](./20260309_tkinter.py)

## 🔘 버튼 이벤트와 대화상자

> 버튼 클릭 이벤트와 messagebox 안내 · 확인 창을 연습한 예제 *(이벤트 · 대화상자)*
>
> - 주요 내용: 클릭 횟수 표시, lambda 콜백, 스타일을 입힌 버튼 묶음, 예 / 아니오 확인 창
>
> [코드 보기 →](./20260320_tkinter.py)

---

## 사용 라이브러리

`tkinter` (`messagebox`, `scrolledtext`)

※ 기본 창과 위젯 예제의 계산 부분은 `eval`을 사용해서 학습용으로만 사용합니다.
