### 변수 초기화와 누적

> **키 큰 사람 수** · [04_10](2026_04_10_codingtest.ipynb)
>
> - 처음 시도: 누적 변수를 값 없이 증가 연산에 사용
> - 원인: 변수 초기화 누락 (`count = count + 1`)
> - 해결: 누적 변수를 `0`으로 초기화한 뒤 조건을 만족하면 증가


```python
total = 0                # 누적 변수 초기화
for i in range(1, 5):
    total = total + i    # 이전 값을 읽어서 새 값으로 갱신
print(total)             # 10
```

| 누적 종류 | 초기값 | 예시 |
|---|---|---|
| 합계, 개수 | `0` | `count = 0` |
| 곱 | `1` | `result = 1` |
| 리스트 | `[]` | `answer = []` |
| 문자열 | `""` | `output = ""` |

> 누적 연산은 이전 값을 읽은 뒤 새 값을 쓰는 구조.
> 읽기 전에 값이 없으면 오류 (셀에서는 `NameError`, 함수 안에서는 `UnboundLocalError`).
> 변수명은 내장 함수명(`sum`, `max` 등)과 겹치지 않게 지정.

### 키워드 인자 (print)

> **인덱스 문자 조합** · [04_10](2026_04_10_codingtest.ipynb), [04_13](2026_04_13_codingtest.ipynb)
>
> - 처음 시도: `SyntaxError: invalid syntax`
> - 원인: 키워드 인자에 `=` 대신 `:` 사용 (`end:""`)
> - 해결: `end = ""`로 고쳐서 04_13에서 완성


| 인자 | 설명 | 기본값 |
|---|---|---|
| `sep` | 값 사이에 넣는 구분 문자 | `' '` |
| `end` | 출력 마지막에 붙는 문자 | `'\n'` (줄바꿈) |

```python
print("a", "b", end="")   # 줄바꿈 없이 이어서 출력: ab 형태
```

> 키워드 인자는 `이름=값` 형태로 전달.
> `:`는 딕셔너리, 슬라이싱, 타입 힌트에 쓰는 기호이며 인자 지정에는 사용 불가.

### pop 과 remove

> **가장 큰 두 수의 곱** · [04_18](2026_04_18_codingtest.ipynb)
>
> - 처음 시도: `IndexError: pop index out of range`
> - 원인: `list.pop()`은 인덱스를 받는데 최댓값(값)을 넣음
> - 해결: 값으로 지우는 `remove()`를 쓰고, `max()`를 두 번 호출


| 메서드 | 삭제 기준 | 반환값 | 예시 |
|---|---|---|---|
| `list.pop(i)` | 인덱스 `i`의 원소 | 삭제한 원소 | `[1, 2, 3].pop(0)` 반환 `1` |
| `list.remove(x)` | 값이 `x`인 첫 번째 원소 | `None` | `[1, 2, 3].remove(2)` |

```python
numbers = [1, 2, 3, 4, 5]
numbers.pop(max(numbers))   # pop(5): 유효 인덱스는 0 ~ 4라서 IndexError
```

> `pop`은 인덱스, `remove`는 값을 기준으로 삭제.
> 값을 알고 있을 때는 `remove`, 위치를 알고 있을 때는 `pop`.

### 문자열 분리와 결합

> **모음 제거** · [04_19](2026_04_19_codingtest.ipynb), [04_20](2026_04_20_codingtest.ipynb)
>
> - 처음 시도: `ValueError: empty separator`
> - 원인: `str.split("")`은 빈 구분자를 허용하지 않음
> - 해결: 문자열을 for로 돌며 모음이 아니면 리스트에 담고 `"".join()`으로 합침


| 방법 | 설명 | 예시 |
|---|---|---|
| `str.split(sep)` | `sep` 기준으로 나눈 리스트 반환 | `"a b".split(" ")` 결과 `['a', 'b']` |
| `str.split("")` | 빈 구분자는 `ValueError` | 사용 불가 |
| `list(str)` | 문자 단위 리스트로 변환 | `list("abc")` 결과 `['a', 'b', 'c']` |
| `"".join(list)` | 리스트 원소를 하나의 문자열로 결합 | `"".join(['a', 'b'])` 결과 `'ab'` |

> 문자열은 불변(immutable) 자료형이라 `remove`, `append` 메서드가 없음.
> 문자열은 for로 문자 단위 순회 가능, 결과는 리스트에 모은 뒤 `join`으로 결합.

### 조건에 맞는 원소만 남기기

> **특정 문자 제거** · [04_15](2026_04_15_codingtest.ipynb)
>
> - 처음 시도: 같은 문자가 여러 개인데 첫 번째만 지워짐
> - 원인: `list.remove()`는 첫 번째로 일치하는 값만 삭제
> - 해결: `filter()` + `lambda`로 조건에 맞는 원소만 남김


| 방법 | 설명 |
|---|---|
| `list.remove(x)` | 값이 같은 첫 번째 원소 1개만 삭제, 원본 변경 |
| `filter(함수, 반복가능객체)` | 함수 결과가 `True`인 원소만 남긴 이터레이터 반환 (원본 유지) |
| `list(filter(...))` | 이터레이터를 리스트로 변환 |

```python
letter = "B"
my_list = list("BCBdbe")
list(filter(lambda x: x != letter, my_list))   # ['C', 'd', 'b', 'e']
```

> `lambda`는 이름 없는 한 줄 함수.
> `filter`는 반환값이 이터레이터라서 리스트로 쓰려면 `list()`로 감싸야 함.
