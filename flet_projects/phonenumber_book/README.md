# 전화번호부 📞
 
Flet으로 만든 전화번호부 관리 앱. 연락처 추가, 검색, 목록 조회, 삭제 기능을 지원합니다.
 
## 🎮 스크린샷
 
| 홈 화면 | 추가 | 목록 | 검색 |
|---|---|---|---|
| ![](./images/home.png) | ![](./images/add.png) | ![](./images/list.png) | ![](./images/search.png) |
 
## ✨ 기능
 
- **추가**: 이름, 전화번호, 이메일, 직장명 저장
- **검색**: 이름으로 연락처 검색
- **목록**: 저장된 모든 연락처 조회
- **삭제**: 연락처 제거
## 🛠️ 실행 방법
 
### 설치
```bash
pip install flet
```
 
### 실행
```bash
python phonebook.py
```
